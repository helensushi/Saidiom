# 🌈 趣味成語樂園 (Cantonese Idiom Learning App)

這是一個專為小朋友設計的成語學習網頁應用程式。具備色彩繽紛的卡片設計、廣東話語音朗讀功能，以及智能隨機測驗，幫助小朋友輕鬆有趣地學習成語。

## ✨ 功能特色

- **🎨 視覺記憶卡片**：8 色循環漸變主題，配上可愛 Emoji，加深視覺記憶。
- **🔊 雙重發音系統**：支援廣東話語音，可分別朗讀成語、解釋及例句。
- **✍️ 智能隨機測驗**：每次隨機抽取 10 題，包含三種不同題型（看解釋選詞語、例句填空、看詞語選解釋）。
- **📱 響應式設計**：完美支援手機、平板及電腦瀏覽。

## 🚀 本地執行指南

1. 確保已安裝 Node.js
2. 複製此專案：`git clone <你的 GitHub 倉庫網址>`
3. 進入資料夾：`cd idiom-app`
4. 安裝套件：`npm install`
5. 啟動開發伺服器：`npm run dev`

## 🛠️ 技術棧

- React (Vite)
- Tailwind CSS
- Lucide React (圖示)
- Web Speech API (語音合成)
